Bridge

A native macOS workspace for AWS.

Get started

Install the AWS CLI and configure a profile using its normal setup flow. Bridge reads your local AWS configuration; it does not ask you to paste access keys into the app. Complete any required AWS SSO sign-in using the CLI.

Choose a profile and region in the toolbar, then choose a service in the sidebar. Bridge verifies the account before loading resources. Select a row to inspect its details; related logs, roles and queues have direct links.

Demo or real account?

Bridge Demo uses invented profiles, resources and costs. It makes no AWS or model-provider calls. Its window subtitle says “Demo · Sample data”. Open Bridge to use your configured AWS profiles.

Workspaces and costs

Each window tab has its own profile, region and time range. Investigation finds related resources by workload name. Billing covers the selected verified account across all regions and loads only when you click Load costs. Cost Explorer permissions are required and API charges may apply.

AWS Command drawer

The bottom utility bar shows this tab’s request status. Open it with ⌘J or the toolbar’s terminal button, then drag its top divider to resize it. Choose a request from History and switch between Command and Output. Copy copies the displayed preview; Clear removes completed history when idle; Stop cancels active work in this tab.

History holds up to 20 requests in memory. Previews are bounded, sensitive responses are omitted, and secret masking is best effort. Profile, region and time-range changes clear history. Use Operation runner to run supported read operations through Bridge’s normal authorization.

Assistant

Choose Claude Code or Codex in the assistant inspector. The provider must already be installed and signed in. Read the disclosure before enabling it: your messages and AWS results used in an answer can be sent to that provider. Bridge lists the assistant’s read activity.

S3 downloads

Download opens a Save dialog where you can edit the local filename. Existing extensions are preserved. If the S3 key has no extension, Bridge suggests one using the object’s Content-Type metadata, such as content.png for image/png. Unknown file types retain the original name. This does not change the object in S3.

Profile settings

Use Settings to set a display name, expected account, default region, environment color, protected status and permission limit. Service views and the operation runner expose supported reads and downloads.

Requires macOS 14 or later.
