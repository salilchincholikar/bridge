Bridge’s first public **developer preview**, version 0.1.0 (build 2).

## Download

`Bridge-0.1.0-macOS-arm64-preview.zip` is for **Apple Silicon Macs** with a macOS 14+ deployment target. Intel builds and minimum-OS acceptance testing are not included in this preview.

**Ad-hoc signed and unnotarized.** This is not a Developer ID signed installer. macOS may block a quarantined download. This preview is intended for developers comfortable evaluating pre-release software; building from source is an alternative. No Gatekeeper acceptance claim is made.

Extract the ZIP and move `Bridge.app` to Applications. For real AWS use, install AWS CLI v2, configure a named profile and finish any required sign-in first. See the [setup instructions](https://github.com/salilchincholikar/bridge#requirements).

Verify the ZIP against `SHA256SUMS.txt` using `shasum -a 256`. `manifest.json` records the source commit, toolchain, architecture, signing status and packaged files. Checksums detect corruption; they do not establish Apple signing identity.

## Included

- Native macOS service navigation, independent profile/region context per tab and keyboard shortcuts.
- Lambda, CloudWatch Logs, ECS, SQS, IAM, S3 and Alarms workspaces.
- Account-wide billing: daily spend, service breakdown, period comparisons and remaining-month forecast.
- Workload investigations and a command drawer for inspecting supported requests.
- Experimental Swift libraries and opt-in assistant integrations.

The download contains the production app, license, copyright notice and setup information. Demo fixtures, developer configuration, credentials and UI test entry points are excluded.

## Known limits

- Pre-release: broader real-account/provider compatibility, accessibility and OS testing remain ongoing.
- Requires your installed AWS CLI v2 for real requests. AWS permissions still apply; Cost Explorer may incur API charges.
- New or changed credential helpers require approval. Review the [security model](https://github.com/salilchincholikar/bridge/blob/main/docs/security-model.md).
- Optional assistant support is experimental and can send approved data to a model provider.
- No automatic updater, notarization, Intel download or signed installer in this release.

The release workflow runs offline regressions, the independent Core example and bundle checks. It verifies the app again after extracting the final ZIP. Interactive GUI acceptance and a quarantined download test on another Mac are separate checks.
