Go from a resource to its logs, execution role or related workload without rebuilding your context at every step.

01 / EXPLORE

The right account, always in view.

Choose a profile and region, then browse your services. Each native tab keeps its own account context, selection and time range. Compare workspaces side by side.

02 / INVESTIGATE

Follow the workload.

Search by workload name to discover related resources. Inspect configuration, follow log events and move between functions, queues and execution roles.

03 / UNDERSTAND

Give account costs some context.

See month-to-date spend, daily costs, service totals and the remaining-month forecast. Billing covers the verified account across regions, with data loaded when you ask for it.

CLEAR ABOUT WHAT RUNS

Your tools.
A visible execution path.

Uses your AWS CLI

Work with your existing named profiles. Bridge verifies identity and applies its operation policy before requests. New credential helpers require human approval.

Inspectable by default

See request status, duration and bounded previews in the command drawer. Sensitive responses stay out of ordinary history and caching. Redaction remains best effort.

Open to exploration

Read the code, try the in-memory Core example or build on the experimental Swift libraries. Optional assistant integrations require consent and can send allowed data to a model provider.

Requirements & full setup ↗

No AWS credentials or provider account needed. Requires macOS and Swift tools 6.2+.

git clone https://github.com/salilchincholikar/bridge.git
cd bridge
make demo

Install AWS CLI v2 and configure a named profile first. Then build and open the app.

git clone https://github.com/salilchincholikar/bridge.git
cd bridge
make app
open build/Bridge.app
Demo uses fictional data.

Bridge is pre-release software. Broader real-account/provider compatibility, minimum-OS testing and signed distribution are ongoing work. Cost Explorer requires permissions and may incur API charges. Review the security model before using real accounts.
